# KL UI 方案 V3

> 更新日期：2026-11-25
>
> 代码基线：`dev` `960d760`
>
> 目标客户端：Codex Desktop 风格 Avalonia GUI
>
> 技术范围：GUI 只通过 `Kl.Client` 渲染 Core 事件，不复制 Agent/Tool/Policy 逻辑
>
> 验收基线：GUI `260 passed / 0 failed`（另有 7 Avalonia headless、TUI 55）

---

## 1. 设计目标

GUI 不是简单聊天框，而是 Codex 风格的本地编码工作区：

1. 左侧 rail 提供全局入口，中间栏负责项目/会话导航，右侧承载聊天与功能页面。
2. 视觉以 Codex Desktop 为参考，强调深色层级、紧凑尺寸、低对比边框和明确选中态。
3. 高频操作优先：新建会话、切换项目、搜索、置顶、拖拽排序、审批和取消。
4. 页面必须像桌面客户端，而不是网页弹窗集合。
5. 所有内容状态以 Core 事件和 `Kl.Client` 历史为准，UI 只保留必要的本地 UI 状态。

## 2. 三栏结构

### 2.1 顶部窗口框架

- 无系统边框，自绘标题栏。
- 左侧文件/编辑/视图/帮助菜单。
- 右侧最小化/最大化/关闭。
- 标题栏与主内容统一深色背景，不使用亮色系统默认控件。

### 2.2 第一栏：图标 Rail

- 宽度约 `52px`。
- 导航按钮约 `36×36`，图标约 `18px`。
- 入口包括聊天/首页、自动化、资料库、插件、更多；底部设置。
- “更多”菜单支持项目、代码审查与置顶。
- 选中态：深灰填充 + 白色图标；hover/pressed 使用独立低亮色。
- 悬浮提示延迟短，不遮挡第 2 栏内容。

### 2.3 第二栏：会话/项目栏

- 默认宽度约 `280px`，可拖拽调整并收起/展开。
- 顶部产品切换器、搜索、通知和 section actions。
- 项目树、最近会话、置顶会话/项目。
- 支持项目折叠、会话拖拽排序、项目拖拽、hover 预览卡和 section menu。
- 搜索只过滤导航，不改变 Core 历史。
- 滚动条与拖拽热区按 Codex 风格保持窄条和边缘触发。

### 2.4 第三栏：主内容

- 聊天页：header + transcript + composer。
- 项目页：项目列表、进入项目、添加项目。
- 插件页：共享 `~/.kl/plugins` 目录与导入入口。
- 自动化页：任务列表、搜索、筛选、执行与编辑。
- 设置页：独立页面，使用 rail + 设置导航 + 设置内容，不再使用模态弹窗。

## 3. 页面与导航

### 3.1 聊天

- 空状态：星形图标、主标题、项目行（在输入框卡片内）和主 composer。
- 会话状态：顶部会话标题和操作按钮，中间 transcript，底部 composer。
- 用户消息右侧气泡；assistant Markdown 左对齐。
- reasoning/tool/error 使用活动行和状态 badge。
- 审批请求在当前会话内展开，提供 `allow` / `allow_session` / `deny`。
- 发送、停止、附件、模式、权限和模型入口固定在 composer。
- 输入 `/` 弹出命令菜单（`new`/`compact`/`fork`/`settings`/`plugins`/`library`/`doctor`），
  输入 `@` 弹出工作区文件菜单；两者支持 `↑↓` 选择、`Enter` 确认、`Esc` 关闭和点击选择，
  弹出层宽度分别 340 / 400，锚定在输入框上方。
- 权限 chip 是填充胶囊，弹出 Codex 风格三行菜单：请求批准 / 帮我批准 / 完全访问，
  选中行整行橙色并带勾，分别映射 Core 的 `ask` / `auto` / `dontAsk`。
- 模型 chip 弹出推理强度面板：灰色模型行（点击进设置）+ 紫色渐变滑杆；
  四档（默认/低/中/高），拖动磁吸到档位点并实时显示，只有最高档文字与整条轨道变紫，
  低档显示进度色；松手时写一次 Core。

### 3.2 活动行与 Shell 面板

- 单工具调用保持内联活动行。
- 多工具调用按 turn 分组，默认折叠。
- Shell 行采用 `已运行 <command>`，显示命令 chip 和成功/失败状态。
- 展开 Shell 面板显示命令、输出摘要、diff / 详情。
- Chevron 旋转动画只用于展开状态，不造成整行跳动。
- 大输出默认折叠，限制 UI 渲染长度。

### 3.3 Markdown 与代码块

- assistant 内容使用 Markdown 渲染。
- 标题、列表、引用、表格、链接、inline code 和代码块统一样式。
- 代码块采用 header row + 复制/换行操作 + 双色 surface。
- inline code 使用 Codex 风格深色 chip。
- UI 不渲染 ANSI 为 HTML；工具输出按纯文本处理。

### 3.4 对话标尺

- 每个用户 turn 对应一个标尺 tick。
- 滚动时当前 tick 自动高亮；不额外制造假 tick。
- hover 时显示该轮预览卡，预览卡位置即时跟随，不做滞后滑动。
- 点击 tick 跳转，预览卡图标可标记/取消当前 turn。
- 标尺只在有会话时显示，普通空聊天页不显示占位标记。
- 当前/选中标记使用 dash + square 结构，hover 只增长但不破坏方形状态。

### 3.5 设置

- 设置是完整页面，由 rail 固定入口进入。
- 第 2 栏沿用 Codex：标题「设置」+ 搜索框 + 分组标签（个人 / 设置）+ 入口
  「个人：常规 / 通知 / 导入 / 个人资料 / 外观 / 账户 / 已归档的聊天 / 广告设置 /
  家长控制 / 受信任联系人 / 语音 / 存储 / 配置 / 个性化 / 迷你界面和智能伙伴 /
  键盘快捷键 / 使用情况和计费 / 数据管理（另有关联）；集成：插件 / 密码 / 电脑操控 /
  浏览器 / 云电脑；编码：钩子 / 连接 / 代码审查 / Git / 环境 / Worktrees」；打开设置不覆盖 rail。
- 第 3 栏是大标题 + 分区标题（权限 / 常规 / 通知 等）+ 卡片；卡片内每行
  左侧标题与说明、右侧控件，行间用 1px 分隔线。
- 通用设置改动即应用：权限经 Core `permissions.set`，内容字号即时重排；
  不再有「保存通用设置」按钮。
- 常规：权限模式、工作模式、会话排序（最近更新 / 创建时间）、置顶排序
  （手动 / 最近活动），都写回 GUI 状态。
- 通知：通知面板筛选（优先事项 / 已置顶 / 定时任务，持久化）和「全部标为已读」。
- 外观：内容字号、侧边栏宽度预设（窄 / 标准 / 宽，对应 238 / 300 / 360）、
  侧边栏分组（分项目 / 合并）。
- 已归档的聊天：列出归档会话与更新时间，可取消归档；点击行会关闭设置并打开会话。
- 键盘快捷键：Ctrl+N / Ctrl+Enter / Ctrl+F / Ctrl+, / Esc 只读对照表。
- 存储：GUI 状态文件位置、本地统计和添加工作区。
- 使用情况和计费：每个完成回合把输入/输出 tokens 与费用记到对应会话（GUI 状态），
  页面汇总总量并按会话列出；本版本之前的会话没有数据。
- 集成：通过一次性握手连接读取 Core 的 `mcp.list`，不需要先打开聊天会话；
  「刷新」重新探测。
- 记忆：按工作区 / 用户范围列出 Core 记忆条目，可载入编辑、保存、删除和新建，
  全部经 `memory.list/read/write/delete` 写入 Core。
- 配置：显示 KL Home 下 `config.toml` 的路径，并通过一次性握手连接读取
  `config.get` 的脱敏结果（Provider / 模型 / 审批模式 / 推理强度 / 提供方）；
  「打开」直接用系统默认程序打开配置文件。
- 数据管理：显示 GUI 数据目录与 KL Home，可一键打开；「导出」用保存对话框
  把 GUI 状态 JSON 复制到用户选择的位置。
- 插件页侧栏提供「插件 / 技能」两个 tab；技能列表经一次性 `skill.list` 读取
  当前工作区，显示名称与说明；点击技能可经 `skill.get` 查看正文。
- 常规页的「启动时恢复上次会话」使用 Codex 风格开关，关闭后启动总是新会话。
- 栏目对齐 Codex 桌面版：导入、个人资料、账户、广告设置、家长控制、受信任联系人、
  语音、存储空间（占用条 + 文件夹用量）、配置（批准策略/沙盒/网络/搜索/详细程度 +
  模型与 API Key + 当前配置）、个性化（记忆 + 写作 + 语气 + 自定义指令）、迷你界面与
  智能伙伴、快捷键编辑器、使用情况和计费（套餐/限额/重置 + 本地用量）、数据管理
  （共享链接/模型训练/位置/导出）、插件（插件/应用/MCP/市场 + MCP 工具）、密码、
  电脑操控、浏览器、云电脑、钩子、连接、代码审查、Git、环境、Worktrees。
  这些新栏目目前只做 UI，未接后端的数据保持占位或只读展示。
- 使用习惯：记住上次停留的设置页，打开设置时自动把当前导航项滚到可见位置；
  设置内 Ctrl+F 聚焦搜索框，Esc 先清空搜索再关闭设置；详情浮层点遮罩可关闭；
  个人资料的统计与常用插件改为真实数据。
- 交互与动效：分段按钮可切换选中；使用情况/插件/连接/代码审查的分页会切换内容；
  所有暂时没有后端操作的按钮都会打开统一的详情浮层；带箭头的行可点击并带悬停高亮；
  外观模式卡片可选中；切换设置页时内容淡入并轻微下滑、滚动位置回到顶部；
  开关滑块带动画；侧栏导航高度收紧到 32px。
- 设置搜索按整个分区匹配并隐藏无关分区，无结果时显示「没有匹配的设置项」。
- API Key 只显示“是否已配置”，不显示明文；配置修改由 Core 管理。

### 3.6 项目

- 项目入口打开应用内项目页。
- 项目行展示项目图标、名称、路径和进入操作。
- 点击项目进入对应聊天工作区。
- 只有显式点击“添加项目”才打开系统目录选择器。
- 不在点击项目 rail 图标时直接打开系统文件窗口。

## 4. 交互规范

### 4.1 选中与 hover

- Rail 选中：填充块 + 图标提亮，背景和图标状态分离。
- 侧栏行 hover：只改变行背景，不使用整页高亮。
- 菜单行：整行可点击；图钉是独立点击区域。
- 菜单 hover/pressed 使用轻量层级，不允许出现第二套亮色方块。
- 旧选中项切换必须即时取消，不产生闪白或双选中。

### 4.2 动画

- 侧栏收起/展开：约 `200ms` 位移，可取消。
- rail / 菜单颜色：短时过渡，优先稳定而非夸张。
- section menu 和 hover card：快速出现，移动时即时跟随。
- 菜单打开可使用 100ms 淡入 + 3px 位移。
- 悬停底色过渡必须从「同色 alpha-0」开始，不能从 `Transparent`（透明白）开始，
  否则鼠标移出会闪白。
- 活动行 chevron 单图标旋转 90°；展开面板淡入并上移 3px；运行中状态 1.4s 脉动。
- 页面切换 120ms 低对比淡入；对话框/命令面板/弹层 100–120ms 淡入。
- 推理滑杆拖动时实时预览档位，松手才写 Core，避免拖动期间反复拉起进程。
- 禁止动画导致布局抖动、整页重排或点击热区改变。

### 4.3 鼠标热区

- Rail 图标点击区大于图标本身。
- 菜单整行可点击；图钉点击区独立且居中。
- 标尺使用窄条视觉 + 更宽的透明命中带。
- 侧栏拖拽边缘与滚动条热区分离。
- 所有 hover card 不阻塞主内容点击。

## 5. 状态模型

GUI 页面状态与 Core 会话状态分离：

```text
UiSection = Chat | Library | Projects | Plugins | Automation | Settings
CoreState = Connecting | ReadyWriter | ReadyObserver | TurnRunning |
            WaitingApproval | TurnCompleted | TurnFailed | Reconnecting | Failed
```

规则：

- UI 不因 hover/pressed 改变 Core 状态。
- observer 不可提交写入或审批决定。
- 切换会话前取消活动 turn，避免旧事件进入新会话。
- 设置页和其他页面切换不得复制或重建 Core session。
- 空会话不写入历史，只有首次真实发送后才持久化。
- 标尺标记基于真实用户 turn，不插入占位假数据。

## 8. 当前缺口

> 2026-11-25 按 `960d760` 复核。

1. 大历史 transcript 尚未虚拟化；标尺依赖已实现的容器，需先改标尺算法再虚拟化。
2. `@` 菜单只有文件，没有 Skills / Plugins 分组；`/` 命令不支持带参数；
   技能页可查看正文，但还没有启停或编辑控件。
3. 弹层关闭没有淡出（Avalonia Popup 的 light-dismiss 无法在关闭前拦截）。
4. 权限菜单没有 Codex 的第四档「自定义（config.toml）」。
5. 超宽窗口下页面列使用 `MaxWidth` + `HorizontalAlignment="Stretch"`，
   是否在所有页面真正居中尚未实机复核。
6. 拖入文件目前统一走附件流程，非文本/代码格式会被拒绝；没有拖入图片或目录的处理。
7. 设置搜索只过滤当前设置页内的分区，不跨页面检索，也没有命中高亮。
8. 真实 Provider / MCP live smoke 需要凭据或已配置的本地服务。
9. 离线环境下 NuGet 审计（NU1900）可能让 `scripts/build.py` 在 TUI 项目中断，
   项目尚未配置 `-p:NuGetAudit=false` 或 `WarningsNotAsErrors=NU1900`；
   该问题未在离线环境复现确认。

## 9. UI 验收

### 静态验收

- 三栏边界清晰，不出现卡片套卡片。
- rail 图标、按钮、菜单和设置页尺寸与 Codex 参考一致。
- 所有页面只使用统一的深色 token。
- 设置不显示为居中模态框。
- 项目入口不直接打开系统文件选择器。

### 动态验收

- 会话切换无旧选中闪烁。
- 菜单整行可点击，图钉独立点击。
- 标尺 hover/点击/滚动联动正确。
- Shell 活动行展开不跳到底部。
- 侧栏收起和拖拽不抖动。
- 审批面板阻止重复发送并正确取消。
- 输入 `/` 与 `@` 弹出对应菜单，键盘与点击都能选中，Esc 关闭。
- 权限胶囊三档切换即时生效并写入 Core（`ask` / `auto` / `dontAsk`）。
- 推理滑杆可点可拖、吸附四个档位、拖动时文字实时更新、只有最高档变紫、
  松手写入 Core。
- 鼠标悬停进出任何按钮/菜单行都没有闪白或突亮。
